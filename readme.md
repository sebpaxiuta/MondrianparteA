# Mondrian parte 1
Para construir a composição, defini um espaço de 800 por 800 píxeis com um tom de fundo cru para simular a textura da tela. Posicionei os três blocos de cor primária — o retângulo vermelho no topo esquerdo, o bloco amarelo na margem inferior esquerda e o bloco azul na zona inferior direita — utilizando coordenadas exatas através de retângulos sem contorno. De seguida, desenhei a grelha ortogonal com linhas pretas de doze píxeis de espessura e pontas diretas, delimitando os espaços e encaixando os blocos com exatidão.
